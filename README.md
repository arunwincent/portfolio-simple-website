# 🌐 Personal Portfolio Website

## 👋 Welcome!

Welcome to my personal portfolio website!

This is a simple beginner-level portfolio project created using **HTML and CSS**. 
I created this project as part of my journey in learning web development and to 
practice my HTML and CSS skills through a real-world project.

The portfolio provides a simple introduction about me, my interests, and my 
upcoming future projects.

---

## 📌 About the Project

This portfolio website is designed with a clean and simple layout. 
It demonstrates my understanding of basic HTML structure and CSS styling.

The website contains two pages:

- 🏠 **Home Page**
- 📞 **Contact Page**

---

## 📄 Pages

### 🏠 Home Page

The Home page includes:

- Personal introduction
- About Me
- My Interests
- Upcoming Future Projects
- Contact button

### 📞 Contact Page

The Contact page provides information that visitors can use to get in touch with me.

---

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the website
- **CSS3** – Used for styling, colors, fonts, spacing, and layout

---

## 🎯 Project Purpose

The main purpose of this project is to strengthen my understanding of HTML and CSS 
by building a simple portfolio website from scratch.

Through this project, I practiced:

- HTML page structure
- Headings and paragraphs
- Links and lists
- External CSS
- CSS selectors
- Colors and fonts
- Padding and margins
- Box model
- `display: inline-block`
- `vertical-align`
- Creating multiple HTML pages
- Linking pages together
